## 原生 IP、家宽 IP 和住宅 IP

原生 IP 机场通常强调 IP 注册地区与出口地区一致；家宽 IP 机场和住宅 IP 机场强调更接近普通家庭网络的地址属性。不同数据库的识别结果可能不一致。

它们常用于 TikTok 机场、直播机场和解锁流媒体机场，但平台策略随时变化，不能保证 Netflix、TikTok 或其他服务永久可用。

## 常见亚洲节点

香港机场和香港节点机场通常延迟较低，香港低延迟机场适合网页和日常使用；香港 IPLC 机场更强调高峰链路。

台湾机场、日本机场、新加坡机场和韩国机场是常见流媒体及地区内容方向。日本原生 IP 机场适合需要日本地区识别的场景，日本游戏机场还要重点观察游戏服务器延迟。新加坡专线机场常用于东南亚和跨境业务。

## 欧美节点

美国机场、英国机场、德国机场和法国机场适合对应地区内容、办公或网站测试。美国流媒体机场选择较多，但距离较远，不能只追求带宽而忽略延迟。

## 东南亚节点

马来西亚机场、泰国机场、越南机场和菲律宾机场适合当地内容、跨境电商和地区业务。节点较少时，应关注维护频率和备用线路。

## 选择关键点

先确认目标服务需要哪个地区，再测试 IP 数据库识别、DNS 泄露、持续连接和账号环境。不要频繁跨地区切换同一账号，也不要把“原生”当作绕过平台规则的保证。
